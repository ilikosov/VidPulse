# E2E test cases — Media Library drawer

Сценарии для e2e (Playwright) раздела **Media Library**, который теперь открывается как
**drawer** с навигацией во внутреннем состоянии (без изменения URL браузера). Реализовано в
PR #187: пункт меню «Media Library» открывает `Drawer`, внутри которого живёт собственный
`MemoryRouter` с прежним деревом роутов `/dictionary/*`.

> ⚠️ **Регрессия:** существующий `dictionary-navigation.e2e.ts` написан под старое
> поведение (`page.goto('/dictionary/tools')`, `toHaveURL(/\/dictionary\/groups$/)`). После
> переноса в drawer прямого URL `/dictionary/*` больше нет, а клики по вкладкам **не меняют**
> адресную строку. Этот спек нужно переписать под drawer-семантику (см. кейсы MLD-02/03) или
> заменить им набор ниже.

## Соглашения и сетап (как в текущем suite)

- Перед каждым тестом — `resetDatabase()` (`helpers/db.ts`); сид данных через
  `e2eDb('<table>').insert(...)` или импорт media-library JSON.
- Стартовая точка приложения — `/videos` (заголовок `Video Library`). Раздел библиотеки
  доступен **только** через drawer, отдельной страницы у него больше нет.
- Селекторы (Ant Design): пункт меню — `getByRole('menuitem', { name: 'Media Library' })`
  (текстовый пункт, не ссылка); drawer — контейнер `.ant-drawer` с заголовком
  `.ant-drawer-title` = `Media Library`; вкладки — `getByRole('tab', { name })`;
  активная вкладка — `.ant-tabs-tab-active`; закрытие — кнопка `.ant-drawer-close` / `Escape` /
  клик по маске `.ant-drawer-mask`.
- Предлагается добавить page object `pages/MediaLibraryDrawer.ts` с методами:
  `open()`, `expectOpen()`, `openTab(name)`, `expectActiveTab(name)`, `openGroup(name)`,
  `back()`, `close()`, `expectClosed()`, `currentUrl()`.

Каждый кейс: **Предусловие → Шаги → Ожидаемый результат**. Везде, где указано
«URL не меняется», проверяется `expect(page).toHaveURL(<url до действия>)` (обычно
`/videos`).

## 1. Открытие / закрытие drawer

### MLD-01 — Открытие из меню

- **Предусловие:** приложение на `/videos`.
- **Шаги:** клик по пункту меню `Media Library`.
- **Ожидание:**
  - drawer виден (`.ant-drawer` с заголовком `Media Library`);
  - видны 6 вкладок: `Overview`, `Groups`, `Artists`, `Songs`, `Events / Locations`, `Tools`;
  - активная вкладка — `Overview`;
  - **URL остаётся `/videos`** (адресная строка не изменилась).

### MLD-02 — Закрытие drawer

- **Предусловие:** drawer открыт (MLD-01).
- **Шаги:** закрыть тремя способами в отдельных прогонах: (a) кнопкой закрытия, (b) `Escape`,
  (c) кликом по маске.
- **Ожидание:** `.ant-drawer` скрывается; URL по-прежнему `/videos`.

### MLD-03 — Повторное открытие сбрасывает на Overview

- **Предусловие:** drawer открыт, переключён на вкладку `Groups` (или открыта деталь сущности).
- **Шаги:** закрыть drawer → снова открыть из меню.
- **Ожидание:** активна вкладка `Overview` (drawer стартует со свежего состояния —
  `destroyOnClose` + `initialPath`).

## 2. Навигация по вкладкам внутри drawer (без URL)

### MLD-10 — Переключение вкладок

- **Предусловие:** drawer открыт.
- **Шаги:** последовательно кликнуть вкладки `Groups` → `Tools` → `Overview`.
- **Ожидание:**
  - на `Groups` виден заголовок/кнопка `Add Group`;
  - на `Tools` виден заголовок `Media Library Tools` и кнопка `Import Media Library JSON`,
    ссылки `Download JSON Schema` / `Download Example JSON` / `Export Media Library JSON`;
  - кнопка `Import Media Library JSON` **отсутствует** на вкладке `Groups`
    (изоляция контента вкладок);
  - **URL не меняется** ни на одном переключении (остаётся `/videos`).

### MLD-11 — Контент вкладок Artists / Songs / Events

- **Предусловие:** засидить по 1–2 записи в `groups`, `artists`, `songs`, `events`.
- **Шаги:** открыть вкладки `Artists`, `Songs`, `Events / Locations`.
- **Ожидание:** в каждой видна таблица со своими данными (имя артиста / название песни /
  название события), URL неизменен.

## 3. Детальная навигация во внутреннем состоянии

### MLD-20 — Список → деталь группы

- **Предусловие:** засидить группу (например `IVE`); drawer открыт на вкладке `Groups`.
- **Шаги:** кликнуть по названию группы в списке.
- **Ожидание:** внутри drawer открывается страница группы (заголовок с именем группы и её
  данные/видео); **URL не меняется**.

### MLD-21 — Цепочка group → artist → song

- **Предусловие:** засидить группу с артистом и песней, связанные между собой.
- **Шаги:** из группы перейти по ссылке на артиста, затем со страницы артиста — на песню.
- **Ожидание:** каждый переход остаётся внутри drawer, контент соответствует сущности,
  URL неизменен на всём пути.

### MLD-22 — Кнопка «назад» внутри drawer

- **Предусловие:** выполнен переход group → artist (MLD-21).
- **Шаги:** нажать кнопку «назад» на странице артиста.
- **Ожидание:** drawer возвращается на предыдущий экран (страница группы), а не закрывается
  и не трогает историю браузера (`getBackPath(location.state, …)` работает в `MemoryRouter`).

## 4. Перекрёстные ссылки из browser-router → открытие drawer на сущности

> Ссылки на сущности библиотеки, отрисованные **вне** drawer, должны **открывать drawer**
> на нужной странице (через `LibraryLink` / `openLibrary(path)`), а не менять URL.

### MLD-30 — Ссылка на песню из таблицы видео (`/videos`)

- **Предусловие:** засидить видео со связанной песней (`video_songs` + `songs`); на `/videos`.
- **Шаги:** в строке видео кликнуть по названию песни (рендерится `SongLinks`).
- **Ожидание:** открывается Media Library drawer на странице этой песни; **URL остаётся
  `/videos`**.

### MLD-31 — Ссылки group/artist со страницы канала

- **Предусловие:** засидить канал с видео, у которого проставлены `group_id`/`artist_id`;
  открыть `/channels/:id`.
- **Шаги:** кликнуть по имени группы, в отдельном прогоне — по имени артиста.
- **Ожидание:** drawer открывается на странице группы / артиста; URL остаётся
  `/channels/:id`.

### MLD-32 — Ссылки group/artist/song со страницы плейлиста

- **Предусловие:** аналогично MLD-31, но `/playlists/:id`.
- **Шаги:** кликнуть group / artist / song-ссылки.
- **Ожидание:** drawer открывается на нужной сущности; URL остаётся `/playlists/:id`.

## 5. Вложенный drawer видео

### MLD-40 — Открытие видео со страницы сущности (стек drawer'ов)

- **Предусловие:** засидить группу с привязанными видео; drawer открыт на странице группы.
- **Шаги:** в таблице видео группы открыть карточку видео.
- **Ожидание:**
  - поверх библиотечного drawer открывается второй drawer (`VideoCard`);
  - закрытие видео-drawer возвращает к странице группы в библиотечном drawer (он не закрылся);
  - URL не менялся на всём сценарии.

## 6. Удалённые browser-роуты (deep-link больше нет)

### MLD-50 — Прямой переход на `/dictionary/*` не открывает раздел

- **Шаги:** `page.goto('/dictionary/groups')` (и `/dictionary/tools`).
- **Ожидание:** раздел библиотеки как страница **не** рендерится; срабатывает catch-all и
  показывается `Video Library` (`/videos`-контент). Drawer при этом закрыт.

### MLD-51 — Легаси-редиректы удалены

- **Шаги:** `page.goto('/groups')`, `/artists`, `/songs`, `/groups/:id`.
- **Ожидание:** редиректа в раздел нет; отрабатывает catch-all (`Video Library`). Никаких
  ошибок роутера в консоли.

---

## 7. Защита от регрессии роутера

### MLD-60 — Нет ошибки вложенных роутеров

- **Предусловие:** слушать `console`/`pageerror`.
- **Шаги:** открыть drawer (MLD-01), переключить пару вкладок, открыть деталь, закрыть.
- **Ожидание:** в консоли **нет** ошибки `You cannot render a <Router> inside another
<Router>` и иных `pageerror` (drawer-провайдеры подняты над `BrowserRouter`, поэтому
  `MemoryRouter` не вложен).
