# E2E test cases — Files drawer

Сценарии для e2e (Playwright) раздела **Files**, который теперь открывается как **drawer**
(без изменения URL браузера), по аналогии с Media Library (PR #187,
[`media-library-drawer.cases.md`](media-library-drawer.cases.md)). Пункт меню «Files» открывает
`Drawer` с прежним содержимым `FilesPage` внутри. В отличие от Media Library, Files — одна панель
без вложенной навигации/вкладок, поэтому drawer не содержит собственного `MemoryRouter`
(`FilesDrawerProvider` — простой `open`-стейт по образцу `VideoDrawerProvider`).

## Соглашения и сетап (как в текущем suite)

- Перед каждым тестом — `resetDatabase()` (`helpers/db.ts`); сид данных через
  `e2eDb('files').insert(...)` / `e2eDb('videos').insert(...)`.
- Стартовая точка приложения — `/videos` (заголовок `Video Library`). Раздел Files доступен
  **только** через drawer, отдельной страницы у него больше нет.
- Селекторы (Ant Design): пункт меню — `getByRole('menuitem', { name: 'Files' })` (текстовый
  пункт, не ссылка); drawer — контейнер `.ant-drawer` с заголовком `.ant-drawer-title` = `Files`;
  закрытие — кнопка `.ant-drawer-close` / `Escape` / клик по маске `.ant-drawer-mask`.
- Предлагается page object `pages/FilesDrawer.ts` с методами: `open()`, `expectOpen()`,
  `scan()`, `deleteRow(filename)`, `openLinkedVideo(filename)`, `close()`, `expectClosed()`,
  `currentUrl()` (без tab-методов — Files одна панель).

Каждый кейс: **Предусловие → Шаги → Ожидаемый результат**. Везде, где указано
«URL не меняется», проверяется `expect(page).toHaveURL(<url до действия>)` (обычно `/videos`).

## 1. Открытие / закрытие drawer

### FLD-01 — Открытие из меню

- **Предусловие:** приложение на `/videos`.
- **Шаги:** клик по пункту меню `Files`.
- **Ожидание:**
  - drawer виден (`.ant-drawer` с заголовком `Files`);
  - видна таблица файлов и кнопка `Scan Files`;
  - **URL остаётся `/videos`** (адресная строка не изменилась).

### FLD-02 — Закрытие drawer

- **Предусловие:** drawer открыт (FLD-01).
- **Шаги:** закрыть тремя способами в отдельных прогонах: (a) кнопкой закрытия, (b) `Escape`,
  (c) кликом по маске.
- **Ожидание:** `.ant-drawer` скрывается; URL по-прежнему `/videos`.

### FLD-03 — Повторное открытие сбрасывает состояние

- **Предусловие:** drawer открыт, пагинация переключена на страницу 2 (или выполнен скан).
- **Шаги:** закрыть drawer → снова открыть из меню.
- **Ожидание:** таблица открывается заново со страницы 1 (свежий стейт — `destroyOnClose`
  размонтирует `FilesPage` при закрытии).

## 2. Действия внутри drawer

### FLD-10 — Scan Files

- **Предусловие:** drawer открыт; в директории есть несканированные файлы (или замокан ответ
  `POST /api/files/scan`).
- **Шаги:** клик `Scan Files`.
- **Ожидание:** появляется уведомление с итогом (`scanned`/`linked`/`errors`); таблица
  обновляется; drawer не закрывается; URL не меняется.

### FLD-11 — Delete записи

- **Предусловие:** drawer открыт; засидена хотя бы одна запись в `files`.
- **Шаги:** клик `Delete` в строке → подтвердить в `Popconfirm`.
- **Ожидание:** строка исчезает из таблицы; уведомление об успехе; drawer не закрывается.

---

## 3. Вложенный drawer видео

### FLD-20 — Открытие связанного видео (стек drawer'ов)

- **Предусловие:** засидить файл, связанный с видео (`files.video_id`); drawer Files открыт.
- **Шаги:** кликнуть по названию видео в колонке `Video`.
- **Ожидание:**
  - поверх Files drawer открывается второй drawer (`VideoCard`);
  - закрытие видео-drawer возвращает к таблице Files (Files drawer не закрылся, таблица
    перезапрошена);
  - URL не менялся на всём сценарии.

---

## 4. Удалённые browser-роуты (deep-link больше нет)

### FLD-50 — Прямой переход на `/files` не открывает раздел

- **Шаги:** `page.goto('/files')`.
- **Ожидание:** раздел Files как страница **не** рендерится; срабатывает catch-all и
  показывается `Video Library` (`/videos`-контент). Drawer при этом закрыт.

---

## 5. Защита от регрессии роутера

### FLD-60 — Нет ошибки роутера/консоли

- **Предусловие:** слушать `console`/`pageerror`.
- **Шаги:** открыть drawer (FLD-01), выполнить скан, открыть вложенный видео-drawer, закрыть оба.
- **Ожидание:** в консоли нет `pageerror`. (`FilesDrawerProvider` не рендерит собственный
  `Router`, поэтому риск `<Router> inside another <Router>` ниже, чем у Media Library, но
  проверяем по той же практике.)
